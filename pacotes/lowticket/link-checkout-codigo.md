Link do checkout, nunca o código. O link gera um Pix novo; o código já venceu quando o e-mail chega. Se mando o código copiado, a pessoa tenta pagar e o banco recusa. Com o link, ela volta ao checkout, recebe um código válido e conclui. É uma diferença pequena que decide se a recuperação funciona. Eu uso sempre o link nos lembretes e testo clicando nele em outro aparelho para ver se abre direito e mostra o produto certo.

**Exemplo:** A Renata mandava o código no texto do lembrete. Muitas pessoas reclamavam que não funcionava. Trocou pelo link do checkout, e as tentativas de pagamento passaram a dar certo.

**Cuidado:** Teste o link antes de enviar para a lista. Link quebrado numa recuperação é oportunidade perdida.
