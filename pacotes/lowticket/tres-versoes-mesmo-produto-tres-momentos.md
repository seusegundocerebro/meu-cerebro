Tenho três versões do mesmo produto, em três momentos. Uma existe só para mostrar no anúncio, pensada para o clique. Outra é mínima, para validar no teste, entregando o essencial. A terceira é a completa, que só se capricha depois que vende. Separar assim evita gastar semanas em um produto que talvez ninguém queira. Cada versão responde a uma pergunta diferente: gera interesse? Entrega o prometido? Vale expandir? A regra é não gastar tempo de produção na versão seguinte até a anterior ter respondido a sua pergunta com dados reais de visita e compra.

**Exemplo:** O Diego tinha uma ideia de caderno de rotina. Fez três páginas para o anúncio, depois uma versão curta funcional para os primeiros compradores, e só quando vendeu fez o caderno completo.

**Cuidado:** Não entregue a versão do anúncio como se fosse o produto. A mínima precisa cumprir o que a página prometeu.
