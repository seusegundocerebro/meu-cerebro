Quiz só faz sentido com promessa personalizada. Sem isso, ninguém tem motivo para responder tantas telas. A pessoa só dedica tempo se achar que vai receber algo feito para ela. Quando a promessa é genérica, o quiz vira obstáculo, não ajuda. Eu uso quiz quando o produto realmente se adapta às respostas, e deixo isso claro desde o anúncio: responda e receba um plano para o seu caso. Se o produto serve igual para todo mundo, uma página direta resolve melhor e custa menos de manter do que um quiz que promete algo que não entrega.

**Exemplo:** A Paula criou um quiz para um produto igual para todos. As pessoas notaram que a resposta final era a mesma. Passou a usar quiz só em produtos com variações reais conforme o perfil.

**Cuidado:** Quiz sem personalização é isca. Se o resultado é o mesmo para todos, não faça quiz.
