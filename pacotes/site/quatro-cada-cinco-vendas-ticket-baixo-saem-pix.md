A maior parte das vendas de ticket baixo sai no Pix. O checkout se desenha para o Pix primeiro; o cartão é o segundo caminho. Quem compra por impulso quer pagar rápido, sem digitar número de cartão, e o Pix atende isso com um toque.

Por isso abro o checkout com o Pix à vista e o código pronto para copiar. O cartão fica disponível, mas sem protagonismo. Conferir que o Pix funciona bem no celular, sem passos extras, é parte do trabalho de conversão. Um fluxo pensado para o cartão atrapalha quem quer pagar pelo Pix.

**Exemplo:** Renata ajusta o checkout para mostrar primeiro o botão do Pix, com o código copiável, e deixa o cartão logo abaixo.

**Cuidado:** a proporção varia por público. Olhe os seus pedidos antes de generalizar.
