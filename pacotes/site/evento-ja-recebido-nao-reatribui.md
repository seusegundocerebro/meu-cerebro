Evento já recebido não se reatribui. Reenviar com o mesmo id é descartado; o ganho de casamento vale só daqui para frente. Se melhoro a qualidade dos dados depois, os eventos antigos não ganham os novos campos.

Por isso acerto o formato antes de abrir volume. Quando faço uma melhoria, ela vale para os próximos eventos. Não perco tempo tentando reescrever o passado. Isso reforça a importância de testar com código de teste e com poucos eventos antes de ligar tudo, porque o que já foi enviado fica como foi.

**Exemplo:** Marcos passa a enviar o telefone com hash e percebe que as vendas anteriores não mudam, só as novas.

**Cuidado:** não gaste esforço tentando consertar o que já entrou. Corrija a origem.
