A API que responde com sucesso pode deixar a imagem quebrada. Mudei a imagem do checkout por API, recebi sucesso, e o banner ficou vazio por alguns minutos. A resposta dizia que deu certo, mas a imagem ainda não estava disponível. Por isso confiro no celular que a imagem carregou.

Depois de qualquer alteração visual no checkout, abro o link como cliente e olho. Se algo estiver faltando, espero e tento de novo. O sucesso da API só significa que o pedido foi aceito, não que o resultado está correto à vista. Quem vai pagar vê a tela, e é a tela que importa.

**Exemplo:** Marcos troca a imagem pela API, vê a mensagem de sucesso e, ao abrir o checkout no celular, nota o espaço vazio. Espera e reconfere.

**Cuidado:** não considere a mudança concluída até ver o resultado na tela do cliente.
