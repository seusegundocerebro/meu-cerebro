Este é o seu cérebro. Cada bolinha do mapa é uma nota, cada fio é uma ligação entre duas ideias.

Pra começar, abra o Claude Code nesta pasta e digite **/setup**. Em uns 5 minutos ele te conhece e o cérebro nasce com as suas primeiras notas.

Depois é só conversar: quando aparecer algo importante, o Claude guarda sozinho e liga no que você já pensou.
